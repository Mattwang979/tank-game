## 🚀 怎麼開始

### 方法一：開連結直接玩（推薦，手機電腦都可以）

網址：**https://mattwang979.github.io/tank-game/**（設定好 GitHub Pages 之後就能開，見下方）

1. 打開網址 → 按「開戰！」→ 你就是**房主**
2. 按 ⚙ →「複製」或「分享」邀請連結，用 LINE 傳給室友
3. 室友點開連結 → 按「加入戰鬥！」就進來了，**不用安裝、不用登入**
4. 人不夠的話，按 ⚙ →「電腦玩家」可以加電腦；也可以在 ⚙ 裡換模式和地圖

想自己練習的話，大廳下面的 **🤖 單人練習**（跟 3 台電腦混戰）和 **🧟 生存闖關** 都不需要網路，按了馬上開始。

這個版本不需要伺服器。房主的瀏覽器就是伺服器，其他人用 WebRTC 直接連到房主。
所以房主要**保持遊戲畫面開著**：手機房主不要切到別的 App 或鎖螢幕，遊戲會自動保持螢幕常亮。
大家連同一個 Wi-Fi 最穩，不同網路通常也連得上。

> 有些手機行動網路或公司網路比較嚴格，可能會連不上房主。這時改用同一個 Wi-Fi，或是用下面的方法二。

#### 一次性設定：開啟 GitHub Pages

1. GitHub repo → **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**
2. 把程式合併到 `main`（或到 **Actions → Deploy to GitHub Pages → Run workflow** 手動執行）
3. 跑完之後就能用上面的網址開了，之後每次推到 `main` 都會自動更新

### 方法二：自己開伺服器（區網，不需要網際網路）

需要 [Node.js](https://nodejs.org/) 16 以上的版本。

```bash
npm install
npm start
```

終端機會顯示：

```
  本機：   http://localhost:3000
  區網：   http://192.168.x.x:3000   ← 室友連這個
```

室友連同一個 Wi-Fi，開「區網」那行網址，輸入同一個房間代碼就能進同一場。

> **Windows 第一次執行時**如果跳出防火牆視窗，要按「允許存取」，不然室友會連不進來。
> 要換 port 的話：`PORT=8080 npm start`（Windows PowerShell 用 `$env:PORT=8080; npm start`）

## ⚔️ 技術要素

- **反彈砲彈**：砲彈打到鋼牆會反彈一次。瞄準線會顯示第一次反彈的方向（穿過傳送門也會顯示），可以繞牆打掩體後面的人。反彈後的砲彈**也會打到自己**。
- **彈藥管理**：最多 4 發，每 0.6 秒補 1 發，準星外圈會顯示。全部打光就只能等補彈。
- **砲彈互撞**：兩顆砲彈相撞會一起消失，可以拿自己的砲彈擋對面的砲彈。追蹤飛彈被打下來會小爆炸。
- **衝刺**：瞬間加速，冷卻 2.2 秒，用來閃子彈或拉近距離。
- **地雷**：埋下 0.9 秒後啟動並對敵人**隱形**，敵人要靠得很近才看得到閃爍的紅點。用砲彈打中地雷可以提前引爆，引爆者算擊殺。
- **草叢**：躲在裡面敵人看不到你，靠很近或你一開砲就會暴露。
- **油桶**：射爆會造成範圍傷害和擊退，還會連鎖引爆附近的油桶和地雷，25 秒後重生。
- **磚牆**：打 3 下會碎，爆炸可以直接炸開，霰彈砲一發就能轟掉，地形會越打越開闊。
- **冰面**：開上去加速和煞車都很慢，會一直滑，但最高速度比較快。
- **傳送門**：坦克或砲彈進入傳送門，會從地圖另一頭（以中心點對稱）的同色傳送門出來，方向不變。可以用來偷襲或逃命。
- **加速帶**：開上去會往箭頭方向被彈出去，還是可以左右閃。
- **擊退**：爆炸會把坦克炸飛，可以把人炸進地雷或油桶堆。
- **逼死**：敵人被你打過之後 4 秒內自爆（被自己的反彈砲彈、地雷或毒圈弄死），擊殺算你的。

## 🛠️ 技術架構

```
shared/core.js    共用物理：坦克移動、冰面 / 加速帶 / 傳送門、牆面碰撞、砲彈反彈、射線
shared/game.js    房間 / 對戰邏輯（權威模擬）：6 種模式、武器、爆炸、道具、計分、獎項、可見度過濾
shared/bot.js     電腦 AI：BFS 尋路（會走傳送門）、走位、預判射擊、閃避、特殊武器、模式目標（搶旗、佔山、躲毒圈）
shared/maps.js    地圖（ASCII 繪製，自動鏡射對稱）、地面風格、旗座、山頭位置
server/index.js   方法二的 Node 伺服器：HTTP + WebSocket，60Hz 固定步長主迴圈
public/net.js     連線層：WebSocket（Node 伺服器）、P2P（PeerJS / WebRTC，房主瀏覽器跑模擬）、單人模式（不連網路）
public/profile.js 成長系統：經驗值、等級、成就、外觀解鎖（存在 localStorage）
public/touch.js   手機雙搖桿操作
public/           其他瀏覽器端程式：Canvas 繪圖（鏡頭跟隨、小地圖）、WebAudio 合成音效、預測與內插
scripts/build-static.js   產生給 GitHub Pages 用的靜態網站（dist/）
```

- **同一份遊戲邏輯，三種跑法**：`shared/` 的程式在 Node 和瀏覽器都能執行。用 Node 伺服器時由伺服器模擬；用 GitHub Pages 時由房主的瀏覽器模擬；單人模式直接在自己的瀏覽器模擬。
- **P2P 配對**：用 PeerJS 的免費公用配對伺服器交換連線資訊，之後的遊戲資料直接在玩家之間傳輸。房間代碼就是房主的 ID，第一個用這個代碼進來的人自動成為房主。
- **權威模擬**：所有判定都由伺服器或房主決定，草叢裡 / 隱形的敵人和隱形地雷不會傳給看不到的玩家，所以沒辦法作弊偷看。
- **本地預測 + 校正**：自己的坦克用同一份物理程式碼即時預測（包含冰面、加速帶、傳送門），收到權威狀態後重播尚未確認的輸入。`test/predict-test.js` 在 150ms 延遲下驗證預測誤差為 0。
- **內插**：其他坦克延遲 80ms 平滑內插；砲彈則從最新快照往前外插（包含反彈和傳送門），所以畫面上的砲彈沒有延遲。

### 測試

```bash
npm test
```

這會：
1. 檢查每張地圖的尺寸、邊界、連通性、旗座、山頭和傳送門配對
2. 回歸測試（三連發）、連線協定測試
3. 在 8 張地圖 × 6 種模式各讓 6 隻電腦打 2.5 分鐘，確認沒有錯誤、真的有交戰，而且搶旗、佔山、吃雞、闖關都真的有在進行
4. 模擬 150ms 延遲開過傳送門、加速帶、冰面，確認本地預測和伺服器完全一致

### 自訂地圖

在 `shared/maps.js` 裡加一個物件，畫左上 16×10（`quad`，四向鏡射）或上半 32×10（`half`，180° 旋轉）就可以。
可以用的地形：`#` 鋼牆、`B` 磚牆、`~` 水、`,` 草叢、`X` 油桶、`i` 冰面、`O` 傳送門、`> < ^ v` 加速帶，`S` 出生點、`P` 道具點。
另外可以設定 `theme`（地面風格）、`flag`（紅隊旗座位置）、`hills`（山頭位置）。
跑 `node test/map-check.js -v` 會印出完整地圖，並檢查出生點是不是都走得到、傳送門有沒有成對。
